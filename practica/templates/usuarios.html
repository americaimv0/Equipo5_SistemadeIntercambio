Sobre este Proyecto

Bienvenido a nuestra aplicacion web crear una plataforma web en Django donde las personas puedan donar utiles escolares que ya no necesitan

y otras personas puedan solicitar o recibir aquellos que necesitan para continuar con sus estudios.

Propositos para el proyecto:

  • Facilitar la donación y recepción de útiles escolares
  • Conectar a quienes tienen materiales con quienes los necesitan
  • Fomentar la solidaridad y reutilización
  • Apoyar a estudiantes para que tengan más oportunidades de aprendizaje
  • Utilizar la tecnología para generar un impacto positivo en la comunidad

Pasos del Proyecto

A continuacion se mostraran los pasos para llevar la app web:

  1. Identificar el problema y plantear la solución.
  2. Diseñar la plataforma y sus funciones.
  3. Crear el proyecto en Django.
  4. Desarrollar el sistema de donaciones y solicitudes.
  5. Realizar pruebas y corregir errores
  6. Presentar el proyecto funcionando
